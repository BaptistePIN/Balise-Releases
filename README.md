# BALISE

Chronométrez vos spéciales VTT enduro avec le seul GPS de votre téléphone.
Aucune puce, aucun tapis, aucun matériel : deux points GPS suffisent.

## Installation

1. Téléchargez `balise.apk` depuis la [dernière version](../../releases/latest).
2. Ouvrez le fichier sur votre téléphone Android (8.0 minimum).
3. Autorisez l'installation depuis cette source si Android le demande.

Les mises à jour suivantes vous sont proposées directement dans l'application.

## Comment ça marche

- **Capturez** un point de départ et un point d'arrivée, chacun avec son rayon de
  tolérance. Sous couvert forestier, 20 à 30 m sont plus fiables que 15.
- **Descendez** : le décompte de 10 secondes se lance au franchissement de la zone
  de départ, le chrono s'arrête tout seul à l'arrivée. Bips et vibrations vous
  guident sans jamais regarder l'écran.
- **Comparez** : créez une session de club, partagez le code à 4 caractères, et
  tout le monde apparaît dans le même classement. Les zones capturées par
  l'organisateur se propagent automatiquement à tous les coureurs.

Le chronométrage continue **écran verrouillé, téléphone en poche**, et fonctionne
entièrement hors réseau — seul le partage entre coureurs a besoin d'une connexion.

## Vie privée

Aucun compte, aucun mot de passe, aucune donnée personnelle collectée. Vos temps
restent sur votre téléphone, sauf si vous rejoignez une session de club — auquel
cas ils sont partagés avec la base que votre club a lui-même configurée.
